## Что я понял

- Обычная программа работает по явным правилам.
- ML-модель обучается на данных.
- Параметры модели — это обучаемые weights и biases.
- Loss function измеряет ошибку модели.
- Gradient descent обновляет параметры в сторону уменьшения loss.
- Training меняет параметры, inference использует уже обученные параметры.
- Overfitting — это плохое обобщение на новые данные.
- Embedding — это векторное представление объекта.
- RAG ищет внешний контекст и передаёт его LLM.
- AI agent использует LLM, tools, planning и evaluation.
